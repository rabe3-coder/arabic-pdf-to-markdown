# Arabic PDF to Markdown — النسخة المصححة

واجهة عربية ثابتة لتحويل ملفات PDF إلى Markdown باستخدام HTML وCSS وJavaScript.

## ما الذي تم إصلاحه؟
- ربط PDF.js المحلي بالإصدار الموجود في المشروع (`pdf.mjs` و`pdf.worker.mjs`) بدل تحميل إصدار قديم مختلف من CDN.
- استخدام JavaScript ES Module بما يتوافق مع PDF.js الحديث.
- حذف نسخة مصدر Tesseract.js غير الجاهزة للمتصفح من النسخة النهائية؛ تُحمّل واجهة Tesseract.js وملفات المحرك من CDN عند الحاجة.
- استخدام ملفات `ara.traineddata` و`eng.traineddata` الموجودة محليًا، مع `gzip: false` لأنها ملفات غير مضغوطة.
- إعادة استخدام عامل OCR بدل إنشاء عامل جديد لكل صفحة.
- تحسين ترتيب مقاطع النص حسب مواضعها التقريبية على السطر، دون عكس أحرف الكلمات بشكل عشوائي.
- الإبقاء على معاينة Markdown وإمكانية تعديل النص قبل التنزيل.

## التشغيل
1. فك ضغط المجلد كاملًا.
2. افتح المجلد في Visual Studio Code.
3. شغّل `index.html` عبر إضافة Live Server أو خادم محلي يدعم ES Modules وملفات Worker. لا تعتمد على فتحه عبر `file://`.
4. اتصال الإنترنت مطلوب لواجهة Tesseract.js ومحرك OCR. ملفات PDF نفسها تُعالج داخل المتصفح ولا تُرفع إلى خادم التطبيق.

## ملاحظات مهمة
- PDF.js وملفات بيانات اللغات موجودة محليًا.
- Tesseract.js وملفات `tesseract.js-core` تُحمّل من jsDelivr وقت استخدام OCR، لذلك هذه النسخة ليست مستقلة تمامًا عن الإنترنت.
- معالجة ترتيب العربية تقريبية؛ ملفات PDF تختلف في كيفية تخزين النص، وقد تحتاج بعض النتائج إلى تصحيح يدوي.
- OCR بطيء نسبيًا، خصوصًا في الملفات الكبيرة. ابدأ بصفحة أو صفحتين للاختبار.
- لا يحتوي المشروع على Turndown لأنه ليس ضروريًا هنا؛ النص يُحوّل مباشرةً إلى Markdown.

## محتويات المكتبات
- `lib/pdfjs/`: ملفات PDF.js وملف الترخيص.
- `lib/tesseract/lang/`: بيانات OCR العربية والإنجليزية.


## دليل الاستخدام
افتح `guide.html` محليًا عبر Live Server أو بعد نشر المشروع على GitHub Pages. يمكن الوصول إليه أيضًا من زر «دليل الاستخدام وإصلاح العربية» في الصفحة الرئيسية.

## مركز المساعدة
صفحة `guide.html` تحتوي على فهرس، بحث داخل الدليل، تقدم القراءة، مقارنة بين الطرق، أسئلة شائعة، وقائمة تحقق محفوظة محليًا في المتصفح.
