تحويل PDF إلى Markdown وإصلاح النص العربي

دليل لاستخدام MarkItDown أو PyMuPDF4LLM من موجه الأوامر في Windows، ثم تشغيل سكربت بسيط لتنظيف النص الناتج. يمكنك نسخ الأوامر مباشرةً.

قبل البدء: هذه الطريقة تعمل بأدوات Python على جهازك، وهي منفصلة عن أداة التحويل الموجودة في الصفحة الرئيسية والتي تعمل داخل المتصفح.

اختر قسمًا من الفهرس أو ابحث عن الخطوة التي تحتاجها.

Python تثبيت الأدوات التحويل سكربت الإصلاح مقارنة الأدوات حل المشكلات قائمة التحقق

1 التحقق من Python

افتح CMD أو Terminal واكتب الأمر التالي:

CMD / PowerShell
python --version

إذا ظهر رقم إصدار، فهذا يعني أن Python متاح من سطر الأوامر. إذا لم يظهر، ثبّت Python من الموقع الرسمي وتأكد من تفعيل خيار إضافته إلى PATH أثناء التثبيت.

2 تثبيت أدوات التحويل

لتثبيت MarkItDown مع إضافاته:

CMD / PowerShell
python -m pip install "markitdown[all]"

بديل يمكنك تجربته لاستخراج PDF مع تخطيط الصفحة:

CMD / PowerShell
python -m pip install pymupdf4llm
قد تختلف جودة استخراج العربية بين ملف وآخر. لا تفترض أن إحدى الأداتين ستكون الأفضل دائمًا؛ اختبرهما على صفحات من ملفك وقارن النتيجة.

3 الانتقال إلى مجلد الملف

في CMD انتقل إلى المجلد الذي يحتوي على ملف PDF. مثال توضيحي (عدّل المسار بما يناسب جهازك):

CMD
cd "C:\\Users\\YourName\\Documents\\PDFs"

تحقق من أسماء الملفات الموجودة في المجلد:

CMD
dir

استبدل input.pdf في الأمثلة التالية باسم ملف PDF الحقيقي.

4 تحويل PDF إلى Markdown

باستخدام MarkItDown:

CMD
python -m markitdown input.pdf -o output.md

باستخدام PyMuPDF4LLM:

CMD
python -c "import pymupdf4llm; open('output.md','w',encoding='utf-8').write(pymupdf4llm.to_markdown('input.pdf'))"
إذا كان اسم الملف يحتوي على مسافات، استخدم الاسم بين علامتي اقتباس داخل الأمر، أو أعد تسميته مؤقتًا إلى اسم بسيط.

5 إنشاء سكربت تنظيف العربية

أنشئ ملفًا باسم fix_arabic_md.py في المجلد نفسه، ثم انسخ الكود التالي واحفظه بترميز UTF-8.

Python · fix_arabic_md.py
import re
import sys
from pathlib import Path


def fix_arabic_text(text: str) -> str:
    # إزالة التطويل العربي وتنظيف المسافات الأفقية الزائدة.
    text = text.replace("ـ", "")
    text = re.sub(r"[ \t]+", " ", text)

    # حذف المسافات الموجودة قبل نهاية السطر.
    text = re.sub(r"[ \t]+\n", "\n", text)

    # تقليل الأسطر الفارغة المتكررة دون تغيير فواصل Markdown.
    text = re.sub(r"\n{3,}", "\n\n", text)

    # علامة اتجاه خفية في بداية الأسطر التي تحتوي على أحرف عربية.
    lines = []
    for line in text.splitlines():
        if re.search(r"[\u0600-\u06FF]", line) and not line.startswith("\u200f"):
            lines.append("\u200f" + line)
        else:
            lines.append(line)

    return "\n".join(lines).strip() + "\n"


def main() -> int:
    if len(sys.argv) != 2:
        print("الاستخدام: python fix_arabic_md.py ")
        return 1

    input_path = Path(sys.argv[1])
    if not input_path.is_file():
        print(f"خطأ: الملف غير موجود: {input_path}")
        return 1

    try:
        content = input_path.read_text(encoding="utf-8")
        fixed_content = fix_arabic_text(content)
        output_path = input_path.with_name(f"{input_path.stem}_fixed.md")
        output_path.write_text(fixed_content, encoding="utf-8")
        print(f"تم حفظ الملف بعد التنظيف: {output_path}")
        return 0
    except UnicodeError:
        print("تعذر قراءة الملف بترميز UTF-8. تحقق من ترميز الملف.")
        return 1
    except OSError as exc:
        print(f"حدث خطأ أثناء قراءة الملف أو حفظه: {exc}")
        return 1


if __name__ == "__main__":
    raise SystemExit(main())
حدود السكربت: ينظف المسافات والتطويل ويضيف علامة اتجاه لبعض الأسطر، لكنه لا يعيد بناء الكلمات التي استخرجتها أداة PDF بحروف منفصلة، ولا يصلح كل حالات ترتيب العربية. احتفظ دائمًا بالملف الأصلي وقارن الناتج قبل الاعتماد عليه.

6 تشغيل سكربت الإصلاح

نفّذ الأمر التالي في المجلد نفسه، مع استخدام اسم ملف Markdown الذي أنشأته:

CMD / PowerShell
python fix_arabic_md.py output.md

سيُنشأ ملف جديد باسم output_fixed.md. إذا كان اسم الملف الأصلي مختلفًا، سيتبع الملف الجديد الاسم نفسه مع إضافة _fixed.

الطريقةمتى تستخدمها؟نقاط الانتباه
أداة المتصفح في هذا المشروعتجربة سريعة دون تثبيت Python، مع إمكانية معالجة الصفحات المصوّرة إذا كانت إعدادات OCR متاحة.تعتمد على المكتبات المحمّلة في المتصفح؛ جودة ترتيب العربية تختلف حسب الملف.
MarkItDownتجربة تحويل من CMD ضمن سير عمل محلي.قد يحتاج إلى إضافات أو إعدادات بحسب نوع الملف؛ راجع الجداول والترتيب بعد التحويل.
PyMuPDF4LLMتجربة استخراج تراعي تخطيط الصفحة وتنتج Markdown.لا يضمن إصلاح كل حالات النص العربي أو التعرف على الصور دون OCR مناسب.
OCRعندما تكون الصفحة صورة ولا يمكن تحديد النص داخلها.يتأثر بدقة المسح والوضوح والخط واللغة المختارة.
أفضل اختبار عملي: اختر صفحة ممثلة من ملفك، وحوّلها بأكثر من طريقة، ثم قارن الكلمات والعناوين والقوائم يدويًا قبل اعتماد النتيجة.

الأمر python غير معروف في CMD

جرّب:

CMD
py --version

إذا عمل الأمر، يمكنك استخدام py -m pip بدلًا من python -m pip. إذا لم يعمل أي منهما، تحقق من تثبيت Python وإضافته إلى PATH.

ظهرت رسالة خطأ أثناء تثبيت المكتبة

اقرأ آخر سطور الخطأ أولًا، وتأكد من اتصال الإنترنت وإصدار Python. لا تكرر أوامر تثبيت عشوائية؛ انسخ رسالة الخطأ كاملة لتحديد السبب.

النص العربي يظهر حروفًا منفصلة أو كلمات بترتيب خاطئ

قد يكون السبب طريقة تخزين النص في PDF أو ترتيب العناصر التي استخرجتها الأداة. علامة RTL تؤثر في العرض غالبًا، لكنها لا تعيد بناء النص التالف. جرّب محرك استخراج آخر، وافحص النص الناتج قبل تشغيل أي إصلاح.

الملف لا يحتوي على نص قابل للتحديد

قد يكون PDF ممسوحًا كصور. ستحتاج إلى OCR للتعرف على الحروف. تأكد من اختيار العربية ضمن لغات OCR، ثم راجع النتيجة لأن التعرف الآلي قد يخطئ.

زر نسخ الأوامر لا يعمل

قد يمنع المتصفح النسخ خارج سياق آمن. شغّل الموقع عبر Live Server أو عنوان HTTPS، أو حدّد الكود يدويًا وانسخه.

✓ قائمة تحقق قبل اعتماد الملف

علّم العناصر بعد مراجعتها. يتم حفظ الاختيارات في المتصفح على هذا الجهاز فقط.

لا تعتمد على سكربت التنظيف وحده للتأكد من صحة المحتوى؛ التنظيف الشكلي قد لا يصلح أخطاء الاستخراج.

✓ أي طريقة أختار؟

  • الصفحة الرئيسية للمشروع: جرّب التحويل مباشرة من المتصفح دون تثبيت Python.
  • MarkItDown / PyMuPDF4LLM: استخدمهما من CMD عندما تريد تجربة محرك استخراج مختلف أو العمل على الملفات محليًا.
  • عندما تكون الصفحة صورة: قد تحتاج إلى OCR. استخراج النصوص من PDF لا يعني بالضرورة أن الأداة ستتعرف على النص داخل الصور.
  • قبل الاعتماد على النتيجة: راجع العناوين والقوائم والجداول واتجاه العربية، واحتفظ بنسخة من PDF الأصلي.
